# REES46

**REES46** — внешняя коммерческая платформа маркетинг-автоматизации / персонализации, упомянута как вторичный ориентир (наряду с [[Mindbox]]) при проектировании конструктора сценариев лояльности проекта [[CustomerJourney-Scenarios-Project|Путь клиента]].

| Атрибут | Значение |
|---|---|
| Тип | Внешний продукт (конкурент/бенчмарк) |
| Источник упоминания | `Блоки для сценариев лояльности.pdf` |
| Роль | Референс для типизации блоков схемы сценария |

## Используется как референс для типов блоков

В сравнительной таблице типов блоков сценария («Блоки для сценариев лояльности.pdf») REES46 представлен как третья колонка (после «В последнем макете» и Mindbox), со своей визуальной нотацией:

| Тип блока | REES46 |
|---|---|
| Стартовое событие | Зелёный блок «Событие» (пример: «Добавление в корзину») |
| Условие | Синий блок «Условие» (пример: «Подписан на канал») |
| Действие | Розовый блок «Сообщение» с метрикой CTR (пример: «Мобильные пуши», CTR 3.6%) |
| Ожидание | Оранжевый блок «Пауза» (пример: «2 мин») |
| Завершение | Не предусмотрено отдельным блоком |

Детальный разбор — см. [[CustomerJourney-Scenario-Model]].
