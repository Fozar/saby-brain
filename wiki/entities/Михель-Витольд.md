# Михель Витольд

Со-ответственный (вместе с [[Свешников-Андрей|Свешниковым А.]]) за реферальную сеть на бою и тестовых стендах — источник: таблица распределения работ [[SabyBank-RKO-Referral]].

## Роль в обсуждениях

- **2026-07-29** — участвовал в проектировании UI истории изменений по офферам/лидам/корешкам реферальной программы (звонок [[zvonok-tim-sveshnikov-mihel-referral-history-ui-2026-07-29]]). Формулировал конкретику: кнопка истории для корешка (по ховеру/в карточке), группировка по корешкам с возможностью развернуть — по аналогии с историей ДК ("в картах такая фигня должна быть"). Финальное решение зафиксировано в [[ReferralProgram-History-UI-Design]].
- Упоминается в звонке [[zvonok-tim-sveshnikov-referral-history-buttons-2026-07-29]] как человек, с которым нужно свериться по деталям истории лидов ("поговори с Витальдом").
