# Полевщиков Евгений

**Полевщиков Е.** — backend-разработчик [[Tensor-Company]] с крупнейшим индивидуальным объёмом трудозатрат в проекте [[CustomerJourney-Loyalty-Scenarios-Project|Путь клиента]] (~50+ чд суммарно), основной реализатор **Сервиса Маршрутов** ([[CustomerJourney-Route-Service-API]]).

## Вклад в проект

**Этап 1.2 (Реестр и карточка сценариев)**:
- `MasterList/4` — мастер для реестра (2д)
- `DetailList/4` — плоский список для реестра в детали (2д)
- Регистрация новой категории маршрута «Лояльность» (2д)
- `Create/3`, `Read/3`, `Update` — CRUD карточки сценария (1д + 3д + 2д)

**Этап 2.1 (Помещение клиента на маршрут)**:
- Доработка модели запуска маршрута (1д)
- `Route.StartTrace/2` (3д, совместно с [[Чусовитин-Александр]])
- `Route.Start/1` (3д), `Route.Stop/1` (1д), `Route.Status/1` (2д)

**Этап 2.2 (Авто-проходчик маршрутов)** — крупнейший блок:
- `AutoTrace.Start/3` (4д)
- `AutoTrace.OnEvent/3` (5д)
- Модуль исполнения этапа по типам: действие/условие/ожидание/завершение/логический блок (15д — самая большая индивидуальная трудозатрата в проекте)
