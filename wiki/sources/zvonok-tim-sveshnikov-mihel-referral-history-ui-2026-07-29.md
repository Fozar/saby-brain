# Звонок 2026-07-29 — дизайн кнопок истории по офферам и корешкам

Navigation: [[Тимошенко А.А.]] | [[Свешников-Андрей]] | [[Михель-Витольд]] | [[ReferralProgram-History-UI-Design]]

Участники: [[Тимошенко А.А.|Тимошенко Александр]], [[Михель-Витольд|Михель Витольд]], [[Свешников-Андрей|Свешников Андрей]] (подключился ближе к концу). Папка «Встречи», ASR-транскрипция, 12:32–12:46. Прямое продолжение [[zvonok-tim-sveshnikov-referral-history-buttons-2026-07-29|звонка 11:53]] — та же тема, Витольд подключён по итогам договорённости «поговори с Витальдом».

> [!note] Средняя достоверность — ASR-транскрипция
> Термины искажены систематически: «офер»/«лофер»/«оффер» — один термин, «корешок»/«крышок»/«корешка» — один термин. Техническое решение восстанавливается уверенно по повторам и контексту.

## Содержание

**Дизайн-решение (зафиксировано к концу звонка):**
- В карточке/на ховере корешка — отдельная кнопка истории **для конкретного корешка**.
- В офере (реестр офферов, при проваливании в конкретный) — кнопка истории **самого оффера**: изменения названия/описания + создание корешков. Текущее поведение (история по всем офферам сразу при проваливании) **не трогаем**.
- Явно решили **не делать двумя историями** (одна общая + одна по корешку одновременно) — Свешников: «двумя историями точно нельзя».
- Вопрос про объединённый сгруппированный реестр (по аналогии с историей дисконтных карт — общий реестр с группировкой по типу карты и разворачиванием) остался опциональным: «если нельзя — оставляем как есть, жмакнем на корешок, не сильно сложно». Тимошенко берёт на проверку техническую возможность.
- Витольд отмечает несоответствие ожиданиям: казалось, что группировка с разворачиванием уже реализована в похожем месте (карты), но по факту список плоский — повод перепроверить смежную реализацию (не привязано к конкретной странице вики, требует отдельной проверки кода).

**Побочная информация (не по теме истории, к концу звонка):** Свешников сообщил, что сегодня создал **вторую реферальную сеть на бою** — по его словам, это готовый «плацдарм», куда будет происходить перенос ([[ReferralProgram-Data-Model|модель данных]] уже документирует механику миграции программы между Реф. Сетями, задача 06096778 — возможно связанный, но не подтверждённый источником как тот же перенос). Также договорённость: Свешников/Тимошенко ждут звонка от Насти по вопросу переноса; детализация по проекту сегодня отправлена Наташей на согласование директору.

## Значение

Закрывает открытый вопрос из первого звонка: итоговая UI-схема — раздельные кнопки истории для оффера и для корешка, без объединения в одну общую историю. Синтез обоих звонков — [[ReferralProgram-History-UI-Design]].
