# Звонок 2026-07-29 — Тимошенко/Свешников: постановка задачи «история изменений»

Navigation: [[Тимошенко А.А.]] | [[Свешников-Андрей]] | [[ReferralProgram-History-UI-Design]]

Участники: [[Тимошенко А.А.|Тимошенко Александр]], [[Свешников-Андрей|Свешников Андрей]]. Папка «Встречи», автоматическая транскрипция речи (ASR), 11:53–12:00.

> [!note] Средняя достоверность — ASR-транскрипция
> Много коротких искажённых фрагментов («выновление», «останто», «Боис», «АИИ») — техническая часть (термины «офер», «корешок», «лид», версии 4100/4200/300) восстанавливается уверенно, разговорные связки — нет.

## Содержание

Обсуждение начинается с уточнения версии реализации (4100/4200) и сроков сдачи «банков» (SabyBank-веток). Свешников формулирует задачу через понятия **офер → лид → корешок**: сейчас в реестре офферов при провале в конкретную программу видна история изменений самой программы (название/описание) и история лидов по ней.

**Ключевой открытый вопрос** — как выглядит история именно по корешку/заявке: своя отдельная история или пишется в общую историю программы? Тимошенко отмечает, что сейчас запись идёт в историю реф. программы, и если нужно разделить — «это надо переделывать». Свешников фиксирует задачу для UI (со слов): нужна кнопка истории в карточке заявки для корешка + возможность поправить параметры прямо со страницы заявки.

Отдельная нерешённая деталь — история сейчас **«сыпется со всех рефпрограмм»** (то есть общая, не отфильтрованная по конкретной), и участники не уверены, баг это или ожидаемое поведение («иерархия против ЕСНР») — договорились уточнить у [[Михель-Витольд|Витольда]] и проверить, кто создавал соответствующую фиксацию требований.

Звонок обрывается на решении собрать отдельное совещание/созвон с Витольдом — это прямое продолжение в [[zvonok-tim-sveshnikov-mihel-referral-history-ui-2026-07-29]] (тот же день, 12:32).

## Значение

Первая часть постановки задачи по UI истории изменений реферальной программы (офферы/лиды/корешки) — детали и решение см. в concept-странице [[ReferralProgram-History-UI-Design]], собранной по итогам обоих звонков.
