## Содержание

Заметки по итогам обзора конкурента [[Mindbox]]. Формулирует понятийную модель проекта: Сценарий, Стартовое событие (определяет объект + ограничение на кол-во исполнений), Объект+Контекст события (примеры: изменение бонусного баланса, покупка совершена/начата), Фильтр (Да/Нет-условие), Действие (работает с объектом+контекстом, порождает контекст действия). Стартовый блок = события + «расписания» — оба типа чётко определяют объект для дальнейшей фильтрации/действий по совместимости типов.
