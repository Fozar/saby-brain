# Source: Путь клиента — Сравнение с конкурентами (шаблон)

**Файл:** `.raw/Путь клиента/Сравнение с конкурентами.pdf`
**Дата ингеста:** 2026-07-03

## Содержание

**Незаполненный шаблон** («Шаблон Сравнение с конкурентами») — стандартная форма Tensor для документирования сравнительного анализа функционала СБИС vs системы конкурента, с инструкцией по заполнению (акцентировать конкурентные преимущества, время выборки/загрузки, скриншоты узких мест). Плейсхолдеры не заполнены применительно к проекту «Путь клиента» — фактическое сравнение с [[Mindbox]]/[[REES46]] содержится не в этом документе, а в `Блоки для сценариев лояльности.pdf` и `Концептуальное решение 2.pdf`.

## Извлечено на страницы

Контента, специфичного для проекта, не извлечено — документ пуст. Зафиксирован факт существования стандартной формы «Сравнение с конкурентами» как часть корпоративной методологии документирования проектов (см. [[Tensor-TechDoc-Standards]]).
