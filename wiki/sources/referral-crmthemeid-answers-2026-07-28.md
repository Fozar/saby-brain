# Диалог 2026-07-28 — CRMThemeId по реф. коду партнёра: ответы на открытые вопросы

Navigation: [[ReferralProgram-CRMThemeId-By-Referral-Code]]

Тема: «Задача в разработку 16.07.26 от Маранов В.Ф.: Просьба реализовать метод для получения целочисленного кода темы отношений по реф коду партнера» (задача №07164990, [[ReferralProgram-CRMThemeId-By-Referral-Code|подробный разбор]]). Участники: Красавин Михаил, Мусохранов Андрей, [[Тимошенко А.А.|Тимошенко Александр]], Ткачук Максим.

## Переписка (2026-07-28)

**12:27 — Мусохранов Андрей** (отвечает на вопросы Тимошенко про метод получения кода темы отношений по реф коду):
1. «По реф коду» — имеется в виду источник партнёра, **`AdObject`**.
2. Откуда зовётся метод — без разницы; главное, что вызывающие будут работать **в аккаунте Тензора**.
3. Если ничего не нашлось — возвращать **`null`**.

**12:51 — Тимошенко Александр**: «А в какую веху задачу надо?»

**12:52 — Ткачук Максим**: сценарий — пользователь переходит из сайта банка (например, Альфа) к нам, нужно создать аккаунт, подключить лицензию, зарегистрировать сделку; банк — партнёр со своим кодом в биллинге. Подтверждает: «в целом да, всё ожидается как Андрей написал». Просит попасть **в 4100/4200**.
