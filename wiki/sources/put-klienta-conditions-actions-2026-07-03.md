# Source: Путь клиента — «Список УсловийДействий.pdf» (2026-07-03)

**Файл:** `.raw/Путь клиента/Список УсловийДействий.pdf` (6 страниц, ~1.04MB, преимущественно скриншоты UI)
**Папка проекта:** `.raw/Путь клиента/` (Customer Journey — сценарии лояльности, ранняя стадия)
**Дата ингеста:** 2026-07-03

## Содержание документа

Справочный документ — **полная выгрузка событийного каталога и построителя фильтров сценарного конструктора Mindbox**, снятая как эталон/словарь для проектирования собственной системы (проект [[CustomerJourney-Loyalty-Scenarios-Project]]). Несмотря на заголовок «Условий/Действий», документ покрывает только раздел «Условия» (события-триггеры + фильтры) — раздел «Действия» не задокументирован в этих 6 страницах.

Структура по страницам:
1. **Заголовок + оглавление** («Условия» / Mindbox / Запуск по событию / Действия клиентов / Заказы) + первый скриншот: конструктор сценария (сценарий 833, черновик) с открытой панелью выбора события — 8 категорий (Действия клиентов, Заказы, Сегментации, Изменения карточки клиента, Изменения продуктов, Лояльность, Рассылки, Прочее); ниже — развёрнутый список подсобытий категории «Действия клиентов» (6 событий) и заголовок «Заказы»
2. Скриншоты: категория «Заказы» (3 события, включая тултип про «Заказ добавлен или изменён»), категория «Сегментации» (2 события + тултип), категория «Изменения карточки клиента» (12 событий)
3. Скриншоты: категория «Изменения продуктов» (3 события), категория «Лояльность» (8 событий), категория «Рассылки» (2 события), категория «Прочее» (1 событие) + заголовок «Расписание»
4. Скриншоты: UI блока «Расписание» — режим «Каждый день» (время, часовой пояс) / «По дням недели» / «По дням месяца» + «Условия запуска» (пример: условие «Клиенту» → «Доступности промокода» / «Наличию продуктов в сегменте», «только одно»)
5. Скриншоты: UI узла «Условие» — построитель фильтров «по Клиенту», логика Все/Любое, панель выбора фильтра (срез 1: Email…Дата рождения [детально] …Заказы и списки продуктов…Программа лояльности…Рассылки)
6. Скриншоты: продолжение панели выбора фильтра (срез 2: Заказы и списки продуктов [подробно]…Программа лояльности…Другие действия — Просмотры продуктов, Просмотры категорий, Изменения списков, Действие клиента, Сессия, Количество дней с действием) + пример настройки фильтра «Промокод»

## Извлечённые страницы вики

- [[TriggerScenario-ConditionsActions-Reference]] — полный структурированный справочник всех событий/фильтров, помеченный как **общий словарь**, на который должны ссылаться другие сценарные документы проекта (например, [[AbandonedCart-Loyalty-Scenario]])

## Ключевые факты

- Событийный каталог Mindbox насчитывает **8 категорий**, суммарно **~36 отдельных событий**, перечисленных в источнике
- Пересечения с существующими подсистемами лояльности Saby: события категории «Лояльность» (промокоды, баланс, карты) семантически соответствуют [[Promocode-Subsystem-Overview]], [[Bonus-Programs-Architecture]], [[DiscountCard-Subsystem-Overview]], [[ReferralDeals-System]]
- Построитель фильтров поддерживает вложенные группы полей (Заказы и списки продуктов / Программа лояльности / Рассылки / Другие действия) с логикой Все/Любое и группировкой ИЛИ
- Раздел «Действия» (шаги сценария — рассылки/SMS/push) в документе отсутствует, несмотря на название — возможно раскрыт в неингестированном `Блоки для сценариев лояльности.pdf` или `События-действия для сценариев лояльности.sabydoc.pdf`
