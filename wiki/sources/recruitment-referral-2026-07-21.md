# Source: Реферальная система в подборе персонала (2026-07-21)

Ингест двух документов из `.raw/Реферальная система в подборе персонала/`:

- **План работ по проекту** (редакция 16 июл 2026) — `online.sbis.ru/shared/disk/de1e5e32-...`

## Суть

Проект «Приведи друга» — реферальная программа для подбора персонала: сотрудники рекомендуют друзей на вакансии, получают вознаграждение (рубли / вирт. валюта / бейдж), когда кандидат доходит до нужной стадии отбора. Третья реферальная вертикаль поверх ядра `ReferralProgram.*` + корешки `ВидЦеныДокумент`, целевой документ — «Кандидат на вакансию».

## Созданные страницы

- [[RecruitmentReferral-Project]] — обзор проекта, бизнес-процесс, архитектура, связи
- [[RecruitmentReferral-TZ]] — полное ТЗ: SabyNet «Карьера», доработки методов, 5 новых API, источники данных UI
- [[RecruitmentReferral-WorkPlan]] — 12 прикладных этапов + технологические; оценки не проставлены

## Ключевые факты

- **Новая SabyNet-конфигурация** «Карьера» (ТЗ) / «Вакансии» (план) — партнёрская сеть, Владелец + Участник; сотрудники становятся партнёрами без приглашения/договоров.
- **Новый тип программы** «Реферальная программа подбора персонала».
- **5 новых API**: Получить реф. ссылку (1д), Создать корешок кандидата (1д), Обновить корешок кандидата (1д), Статистика участника (1.5д), Статистика программы (1.5д).
- **Уникальность корешка**: индекс `(ID_РефПрограммы, ID_ДокументаКандидата)`.
- **Поверхности**: SabyHRM «Подбор персонала», карьерный сайт (site-builder), SabyMy, SabyNet.
- **Лицензирование**: компонент «Подбор персонала», тариф «Вакансии и подбор персонала», политика не меняется.
- **Ранняя редакция**: концепт связи «рефералка ↔ вакансия» не согласован, оценки/сроки не заполнены, много открытых вопросов.

## Не ингестировано

- **Мокапы UI**: встроены как `online.sbis.ru/previewer/...` (site-builder) за авторизацией SBIS + часть битых плейсхолдеров `File.png` — недоступны для транскрипции. Интерактивные прототипы — по ссылкам Axure.
- Внешние `.sabydoc` («Концептуальное описание») и «Описание бизнес-процессов» (БЗ) — по ссылкам, не в папке.
