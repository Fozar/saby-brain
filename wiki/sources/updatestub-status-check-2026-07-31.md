# Статус задачи: ReferralProgram.UpdateStub (SabyBank)

Источник: `raw/Диалоги SBIS/4c01a23b-fb97-45fc-b7ec-7febf745c91f.md` (theme_id `4c01a23b-fb97-45fc-b7ec-7febf745c91f`), задача поставлена 2026-04-30 (Михель В.М.), уточнение статуса — 2026-07-31.

[[Самарина-Ирина]] спрашивает, какой итог по задаче — выглядит несделанной. Тимошенко поясняет: метод `ReferralProgram.UpdateStub` внедрён уже давно; ранее написанный им комментарий «метод не внедрён, передайте тестирование на разработчика» относился к его собственной доброске (подзадаче), а не к сдаче основной задачи — на момент того комментария тестировать со стороны QA было нечего, т.к. метод ещё не использовался.

Чисто статусное уточнение, задним числом закрывающее путаницу вокруг старой задачи по API SabyBank — см. [[ReferralProgram-Stub-Implementation]] (CreateStub/UpdateStub, ревью Мусохранова 2026-06-24).
