# MR-ревью: история изменений корешка заявки реферальной программы

Источник: `raw/Диалоги SBIS/019fb1d0-a23b-7661-b1c8-75882705f334.md` (theme_id `019fb1d0-a23b-7661-b1c8-75882705f334`), 2026-07-30 – 2026-07-31.

Тимошенко открывает ревью MR, повторяя (уже задокументированный) объём решения [[ReferralStub-History-Scope-Cut]]: по договорённости с Мусохрановым в июле делается только история по корешкам — без группировок, без проваливания из истории оффера, без отдельной истории офферов по реферальным сетям. В историю пишутся события создания, изменения статуса, комментария статуса, вознаграждения и других изменяемых полей; запись событий по корешкам в историю самого оффера удалена.

Мусохранов на следующий день (2026-07-31 11:28) задаёт ключевой вопрос ревью: **как в текущем решении показывается история по корешкам только нужной реферальной программы?** Тимошенко отвечает: сейчас общей истории по корешкам нет вообще, только по отдельности (по одному корешку). Мусохранов реагирует: «Звони, что то не то» — переводит обсуждение в звонок (не транскрибирован).

## Связь с последующей работой

Тот же день, позже (12:44) — в отдельном MR-треде [[mr-comment-for-program-method-2026-07-31]] Тимошенко добавляет метод `for_program` в класс истории корешков, возвращающий «объект истории конкретного оффера». По времени и содержанию это выглядит прямым результатом звонка, вызванного вопросом Мусохранова здесь: метод `for_program` закрывает вопрос «как показать историю по корешкам конкретной реферальной программы» без изменения объёма из [[ReferralStub-History-Scope-Cut]] (группировки по-прежнему не делаются, but "по программе" фильтрация — да).

> [!contradiction] Уточнение объёма после ревью
> [[ReferralStub-History-Scope-Cut]] в исходной формулировке фиксировала «сейчас нет общей истории по корешкам. Только по отдельности» как окончательное состояние объёма задачи. Этот источник показывает, что формулировка вызвала возражение ревьюера и потребовала доработки (`for_program`) в тот же день — страница [[ReferralStub-History-Scope-Cut]] обновлена соответствующим разделом.
