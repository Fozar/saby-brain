# Путь клиента — итоговый каталог событий и действий

Navigation: [[CustomerJourney-Scenarios-Project]] | [[CustomerJourney-Scenario-Model]]

Источник: `События-действия для сценариев лояльности.sabydoc.pdf`. В отличие от [[TriggerScenario-ConditionsActions-Reference]] (справочник конкурента [[Mindbox]], используемый как эталон на этапе исследования), этот документ — **собственный целевой каталог**, урезанный до объёма первого релиза проекта («Необходимо обновить, всё не обязательное убрали из проекта»).

> [!note] Вычеркнутые пункты
> В исходнике часть пунктов зачёркнута с пометкой *«Все вычеркнутые не в первом проекте»* — то есть отложены за пределы MVP. Ниже вычеркнутые пункты помечены курсивом.

## События (по прикладным объектам)

| Папка/объект | События первого релиза | Отложено (вычеркнуто) |
|---|---|---|
| **Продажа розницы** | Оплачена | — |
| **Клиент** | Создание | *Удаление, Изменение* |
| **Посетитель сайта** | Первый заход, Каждый заход, Добавление в корзину, Брошенная корзина, Окончена сессия, Заказ создан или изменён | *Продукт просмотрен* |
| **Лояльность → Карта** | Выдана | *Заблокирована, Изменены условия* |
| **Лояльность → Бонусы** | Начисление, Списание, Сгорание | — |
| **Лояльность → Промокоды** | Выдан, Применён, Истекает срок использования | — |
| **Оптовая продажа** | — | *Заказ, Счёт, Реализация* |
| **Отель** | — | *Бронирование номера* |
| **Салон** | — | *Оформлена запись* |

## Действия (7 типов, первый релиз)

1. Отправить сообщение (почта, СМС, уведомления, мессенджеры и пр.)
2. Изменить баланс бонусов
3. Назначить скидку
4. Выдать промокод
5. Добавить/исключить в папку/группу клиентов
6. Назначить тег клиенту
7. Выполнить СПК-код

Этот список 1:1 совпадает с «Действия (23д)» из [[CustomerJourney-WorkPlan]] (Этап 1.1), за вычетом «Назначить тег клиенту», который в плане работ отдельно не упомянут как трудозатрата — возможно учтён в рамках «Добавить клиента в папку».

## Проверка по «Плану тестирования»

`План тестирования.pdf` подтверждает и детализирует этот же набор (см. раздел «Проверка срабатывания всех событий» / «Проверка выполнения всех действий»), с дополнительными нюансами:
- **Создание клиента** — тестируется из 4 источников: реестр клиентов, анкета ДК, SabyGet, продажа, розничные продукты
- **Выдача карты** — из 3 источников: анкета, реестр карт, продажа
- **Начисление/списание бонусов** — вручную, на события, на продаже (розница, СУ, розничные продукты)
- **Промокоды** — все 4 типа (общий/индивидуальный/партнёрский/за активность), каналы: продажа, вручную, SabyGet-регистрация, розничные продукты
- **Назначение скидки** — проверяется отдельно для нового и ранее добавленного в условие скидки клиента
- **Добавление/исключение в папку** — для клиента без папки, в папке, в другой папке
- **Назначение тега** — для клиента с тегом и без тега (подтверждает, что «тег» — реальное действие первого релиза, несмотря на отсутствие явной трудозатраты в плане работ)
