# Задача
№11164628, ошибка на стенде, веха 26.6100, срок 28.11.2026.
https://dev.saby.ru/opendoc.html?guid=01a1e36f-935c-71a9-b766-2457c567f167&client=3

## Где остановились
18.11 пользователь пересобрал стенд; 59 тестов виджетов прошли, включая оба регрессионных. Полный online запущен в фоне, результат пока не получен.
По разрешению пользователя создан и запушен коммит 22934c3d9a. MR СБИС: https://online.sbis.ru/opendoc.html?guid=01a1eafa-ae67-7459-8a6a-5fefdfced30d&client=3

## Что выяснено по коду
GetNewClientsSimple и GetUseCardsSimple запрещали NULL Period на уровне контракта.
Пустая запись вместо периода давала данные только за сегодня. Старые тесты не передавали None.
Оба обновлённых теста до фикса воспроизвели NULL-ошибку и неверный результат пустого периода (2 != 0).

## Решения и почему
Матюшев в переходе задачи указал: без периода возвращать текущий месяц.
Пользователь согласовал снять запрет NULL и использовать весь месяц; явно заданные даты сохраняются.
Тесты проверяют первый и последний дни месяца, исключение соседних месяцев, None и пустую запись.

## Открытые вопросы
Скриншоты перехода не скачаны: лента возвращает ID без URL.
