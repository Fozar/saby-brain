# Группировка офферов по темам (теги направлений бизнеса)

Navigation: [[ReferralProgram-Part2-Project]] | [[ReferralProgram-Folders-Priority-Sprint]] | [[ReferralProgram-Offer-Visibility]]

Концептуальное описание от 17.04.2026 ([[Свешников-Андрей|Свешников А.]]).

**Проблема**: партнёр видит все офферы единым «полотном» — найти нужный сервис под конкретного клиента трудно.

**Решение**: вводим для офферов **теги по направлениям бизнеса**, называем их **темами** (для нового бизнеса, магазины, рестораны, сфера услуг, госсистемы, курсы). У оффера может быть **одна или несколько** тем.

- Владелец при создании/редактировании оффера указывает темы (реализация — на тегах).
- На странице выбора офферов у партнёра: фильтры-чипсы по темам (по умолчанию все офферы), строка поиска по названию оффера.

**Критерий готовности** сформулирован через метрику, а не через факт реализации: *подтверждено статистикой, что партнёры используют фильтр по темам*.

> [!note] Три независимых механизма группировки офферов
> Не путать: **папки офферов** (иерархия `ВидЦены.Раздел`, задаёт владелец, [[ReferralProgram-Folders-Priority-Sprint]]), **папки партнёров** (управляют доступностью, [[ReferralProgram-Offer-Visibility]]) и **темы** (теги оффера для фильтрации партнёром, эта страница). Первое — «где лежит», второе — «кому видно», третье — «про что».
