Передать его API НК, получить конкретные ID точек продаж и дальше фильтровать виджет по этому списку. Собственную выборку из таблиц НК убрать. Контакт по API — Максим Милованов.

## Постановка и критерий

В loyalty_widgets_tools._get_available_companies_only заменить прямые обращения к таблицам Контрагент и НашаОрганизация на НашаОрганизация.MassiveBranchsList/2.

## Что выяснено по коду

Код при ingest не разбирался. Имена методов и описание текущего поведения выше взяты из карточки задачи и разговора; они не подтверждают состояние текущей ветки.

## Решения и почему

Передать владельцам НК трактовку фильтров заведений, чтобы не поддерживать её повторно в лояльности. Точное имя метода берём из карточки: распознавание речи его исказило.

## Открытые вопросы

## Разбор 10.11.2026

- Карточка и полная переписка прочитаны: веха 26.6100, срок 28.11. Алябушев требует переход под фичей; Милованов дал ссылку https://test-cloud.saby.ru/feature-ctrl/page/feature/94256 и сообщил, что на тесте она включена всем. Техническое имя пока неизвестно; браузер требует входа.
- В текущем коде два прямых запроса: продуктовая синтетика (-10/-11/-12/-13/-15) и дочерние организации. -1/-2 обрабатываются отдельно. Признак H/SH сейчас оставляет только выбранную организацию; без него добавляются дети. Это поведение нельзя менять неявно.
- Проверен исходник API в contragents/online, rc-26.6100: MassiveBranches.branches принимает список ID и Record фильтра. Продуктовую синтетику распознаёт сам и включает OnlySalesPoint; результат содержит массив branchs. По умолчанию IncludeASP=True, OnlyActive=False, Visible=True; доступен Depth. Настройки видимости и глубины требуют сверки перед заменой старой выборки.
- encode_params игнорирует пустой allowed_orgs: пустой результат API нельзя передавать как [] без отдельной обработки, иначе пропадёт ограничение по организации.
- Вызов API уже используется в sync/contractor.py. Тесты виджетов находятся в tests/tests_loyaltywidgetsonline/widgets/loyaltywidgets.
- Рабочая папка чистая, открыта чужая для этой задачи ветка 26.6100/bugfix/aatimoshenko/11054160. Код не менялся, техническое решение не согласовано.

Следующий шаг: узнать имя фичи 94256, проверить контракт Depth/Visible и подготовить решение на согласование.

## Фича: уточнение пользователя

Техническое имя фичи №94256 — `our-org-all-product` (сообщено пользователем в этой сессии).
До реализации нужно согласовать границы обхода иерархии: текущая выборка без H/SH включает выбранную организацию и непосредственных детей, с H/SH — только выбранную. Не менять глубину неявно при переходе на API. Семантика конкретных значений Depth пока не подтверждена.
