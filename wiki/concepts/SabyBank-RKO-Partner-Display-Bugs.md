# SabyBank RKO — баги отображения банков-партнёров (кластер 24.07.26)

Navigation: [[SabyBank-RKO-Referral]]

Два бага на стенде, оба заведены Земцовой А.В. с датой ошибки **24.07.26**, оба зафиксированы в переписке 28–29.07.2026, оба в рамках активного тестирования проекта [[SabyBank-RKO-Referral]] (план тестирования: 01.05.26–30.09.26, ответственная — Земцова А.В.).

## Баг 1 — расторгнутый договор всё ещё виден клиенту → инвертировался

Источник: [[sabybank-rko-bug-partner-terminated-contract-2026-07-29]]

- **Исходная жалоба (24.07.26):** банк, **расторгнувший** агентский договор на РКО, продолжает отображаться клиенту в списке доступных банков-партнёров.
- **Апдейт (29.07.26, Акимова И.):** после правки — обратный эффект: банк с **действующим** (заключённым) договором **не приходит** клиенту.

> [!contradiction] Флип поведения
> Похоже на инвертированный фильтр статуса договора в списке доступных банков (`GetBankParticipants` или мастер заявки клиента) — фикс исходного бага сломал противоположный случай. Причина не установлена, требует диагностики (лог `pre-test-go.saby.ru/logs.zdALZ` не расшифрован).

## Баг 2 — новые заявки не видны Владельцу

Источник: [[sabybank-rko-bug-applications-not-shown-sabynet-2026-07-28]]

Новые заявки клиента на РКО не появляются во вкладке «Заявки» детализации оффера в ЛК SabyNet **Владельца** (Тензора). Приложен `.sbislogz` создания заявки под Клиентом, логи не разобраны в рамках ingest.

По модели [[SabyBank-RKO-Referral]] заявка должна создать корешок (`ВидЦеныДокумент`, `ТипСвязи=10`) через `CreateLeadStub` → попасть в `ReferralProgram.GetLeadList/4`. Кандидаты причины: поиск партнёра по цепочке `АккБанка → @Лицо → Карта` не находит участника, либо источник заявки не определяется корректно (см. смежный незакрытый вопрос [[partner-cabinet-source-mechanism-tz-2026-07-28]]).

## Возможная связь между багами

Оба бага играют вокруг одной оси — **определение принадлежности/статуса банка-партнёра** (по агентскому договору для бага 1, по цепочке участника для бага 2). Не исключено, что оба — симптомы одной рассинхронизации данных об участии банка/партнёра в реф. программе, но прямых доказательств связи в переписке нет — фиксируется как гипотеза для дальнейшего расследования.
