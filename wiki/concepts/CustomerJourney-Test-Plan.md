## Функциональные тесты

### 1. Реестр сценариев
Фильтрация, поиск, интерфейс.

### 2. Карточка сценария
- Создание нового сценария
- Вкладка **Описание** — условия запуска, отбора, отображение виджетов (email, начислено бонусов, прошло сценарий, выручка)
- Вкладка **Этапы** — первичная настройка, редактирование этапов действующего маршрута
- Вкладка **Схема** — первичная настройка, редактирование (добавление/удаление/изменение блоков)
- Вкладка **Проходы** (для действующего сценария) — интерфейс, статистика по проходам
- **Карточка прохода** — интерфейс, все этапы прохода, статистика по покупкам

### 3. Проверка срабатывания всех событий (факт помещения клиента на маршрут)
Полная матрица покрытия по каналам — см. детализацию в [[CustomerJourney-Events-Actions-Catalog]]:
- Продажа розницы (оплачена) — во всех розничных продуктах
- Создание клиента — из реестра клиентов, анкеты ДК, SabyGet, продажи, розничных продуктов
- Посетитель сайта (SabyGet) — первый вход, каждый заход, добавление в корзину, брошенная корзина, окончена сессия, заказ создан/изменён
- Выдача карты — через анкету, реестр карт, продажу
- Начисление/списание бонусов — вручную, на события, на продаже (розница, СУ, розничные продукты)
- Сгорание бонусов — по шедулеру
- Выдача/применение промокода — общий/индивидуальный/партнёрский/за активность; на продаже, вручную, в SabyGet при регистрации, в розничных продуктах

### 4. Проверка выполнения всех действий (на любом из событий)
- Отправка сообщения (СМС, почта, мессенджеры)
- Изменение баланса бонусов — без изменения / с начислением / со списанием
- Назначение скидки — новый клиент vs ранее добавленный в условие
- Выдача промокода
- Добавление/исключение в папку клиента — без папки / в папке / в другой папке
- Назначение тега клиенту — с тегом / без тега
- Выполнение СПК-кода — с произвольным кодом (получить от разработки)

## Связь с планом работ

Период тестирования (01.08–28.11.2026) охватывает все функциональные этапы 1.1–2.5 из [[CustomerJourney-WorkPlan]]; выпуск основной функциональности приходится на 01.12.2026 (этапы 2.2–2.5).
