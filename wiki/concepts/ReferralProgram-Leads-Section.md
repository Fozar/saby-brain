# Раздел «Лиды» в ЛК реферальной сети

Navigation: [[ReferralProgram-Part2-Project]] | [[ReferralProgram-SabyNet-Widgets-Redesign]] | [[ReferralDeals-System]]

Концепт «Спринт №1 — Раздел Лиды» (макеты от 26.01.2026, документ обновлён 08.06.2026). Сроки, премиальный фонд и оценки **не проставлены** — концепт остался в шаблонном состоянии в части затрат.

Проблема: на портале реферальной программы есть только раздел «Офферы» со списком программ — чтобы посмотреть заявки, нужно проваливаться в каждую программу. Нового раздела со сквозным списком заявок нет.

**Решение**: отдельный раздел «Лиды» со всеми заявками по всем программам, для **обеих** ролей.

---

## Владелец

- Статистика по лидам **в разрезе месяцев**: месяц, количество лидов во всех состояниях (все партнёры, все программы), сумма вознаграждений по лидам в состоянии «завершено успешно». Верхняя запись — итог за год.
- Реф. программы **в карусели** со статистикой за период (посетители, лиды, сумма вознаграждения партнёрам); клик — фильтрация раздела по программе.
- Список лидов: дата создания, наименование, наименование программы, сумма вознаграждения (только для успешно завершённых), дата изменения статуса, иконка и наименование статуса. Клик — детальная страница заявки.
- Фильтр: период (при этом снимается выделение в блоке периодов), один/несколько партнёров, статус лида, одна/несколько программ.
- Создание лида: выбрать программу → выбрать партнёра → заполнить данные → оформить заявку.
- Поиск по программам.

## Партнёр

То же самое, но без разреза по партнёрам и только по **доступным** программам; при создании лида партнёр программу выбирает, а партнёра — нет. Программы в карусели располагаются по дате принятия участия. Поиск — по программам и по клиенту.

---

## Связь с БЛ

Помесячная статистика «количество лидов + сумма вознаграждений за месяц» — это ровно то, что отдаёт `ReferralProgram.GetLeadPeriodList` (мастер-фильтр периодов), переведённый на корешки в [[ReferralProgram-GetLeadPeriodList-Stub-Mode]]; количество заявок за период добавлено полем `LeadCount` по [[ReferralProgram-Folders-Priority-Sprint|спринту №2]]. Сквозной список заявок по всем программам — реестр «Заявки», переводимый на корешки под фичей `ref_deals_convert` ([[ReferralProgram-RefDealsConvert-Feature]]).
