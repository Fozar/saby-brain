# Мастер-фильтр заявок: вознаграждение без учёта статуса

## Задача

Ошибка на стенде №10269696, автор Тимошенко, ответственный Земцова А.В., срок 05.12.2026, веха не проставлена
(26.10 попросили Земцову). Ссылка: https://online.sbis.ru/opendoc.html?guid=01a17832-297a-75de-8d76-88e6af16bd8f&client=3
Найдено на бою: partners.saby.ru, программа 7660, август 2025, фильтр «Успешно». Мастер-фильтр 4125 ₽,
реестр 4 заявки на 3000 ₽ (500 + 1125 + 500 + 875). Лог `partners-26-10-2026_17-53-25-165.sbislogz`.

## Где остановились

Ошибка заведена 26.10, ждёт вехи. Какая строка на бою даёт лишние 1125 ₽, не проверено: нужно согласие на
SELECT в базе партнёров (`partn2-02@osr-partn2-db1-1`).

## Что выяснено по коду

- `GetLeadPeriodList` (и на бою в `rc-26.5113`) считает Price по `EffectiveDate`, то есть по дате завершения.
  Статус не проверяет: фильтр `Status` из запроса фронта метод не читает.
- Под фичей `ref_deals_convert` в Price попадают корешки любого статуса (`ТипСвязи IS NOT NULL`) с суммой.
  Без фичи берутся строки по сделкам (`Документ IS NOT NULL`), у них статуса нет.
- `GetStubList` с фильтром статуса отбирает по `EffectiveDate` и `ТипСвязи = 15`.
- Корешки хранятся с пустым `Документ`, двойного счёта строк сделок и корешков нет.

## Решения и почему

- Количество считается по месяцу создания, вознаграждение по месяцу завершения: так задумано (Тимошенко, 26.10).
  Количество в мастер-фильтре верное.
- Предложение: под фичей в Price брать только корешки «Успешно» (15). Без фичи статус взять неоткуда,
  этот режим уходит.

## Что нашли на fix (`_0c1708ed`)

Программа 7 «Первый оффер × 666»:
- июль 2025: лишние 300 ₽, у сделки `da4a2f2b...` строка с вознаграждением есть, а корешка нет;
- июнь 2026: 608 против 600 ₽, по сделке 436 восемь строк по 1 ₽ с датой в июне, а корешок («Фонкор») «В работе»,
  вознаграждение 1 ₽ на апреле. В тексте ошибки опечатка: 605 вместо 608.

Остальные программы на fix по суммам сходятся.

## Открытые вопросы

- Что на бою даёт 1125 ₽: корешок не в статусе 15 с суммой или строка сделки без пары. Включена ли фича у
  клиента программы 7660.
