## Этапы (в логическом порядке)

### 1. Новая конфигурация «Вакансии» в SabyNet
Новый тип SabyNet-конфигурации с возможностью добавлять сотрудников аккаунта партнёрами **без приглашения и договоров**. Принадлежность реф. программы к типу даёт отрисовку блока вознаграждения и выбора вакансии на диалоге программы. По клику на плитку «Вакансии» создаётся новая конфигурация.
- Открытый вопрос: единственный или множественный экземпляр на аккаунт (множественный — не проблема; единственный — нужны доработки SabyNet).

### 2. Панель настройки реферальной программы
> [!note] Должна идти раньше страницы «Приведи друга» в SabyHRM — сначала учимся создавать программы, потом отображать.

За основу — панель настройки программы (по сделкам). Доработки:
1. свой компонент условия вознаграждения — выбор этапа или итога (из воронки);
2. свой компонент задания вознаграждения;
3. компонент указания компании и категории;
4. убрать блоки: тема отношений, кому доступно, объявления, форма обратной связи.

### 3. Страница «Приведи друга» для администратора в SabyHRM
Страница настройки реф. программ (пункт Вакансии/Приведи друга). Компонент списка программ: вознаграждение как иконка-бейдж + сумма (рубли или вирт. валюта); если суммы нет — название бейджа. Аналогичная страница в SabyNet сети «Вакансии» — для администратора (владельца) и для сотрудника (участника).
- Права редактирования — ровно как в SabyNet.

### 4. Страница с информацией по реф. программе для администратора
«Провал» в программу по клику в списке. Вкладки:

| Вкладка | За основу | Доработка |
|---------|-----------|-----------|
| Описание/Основная | «Описание» (сделки) | Показ условия и вознаграждения (рубли / вирт. валюта / бейдж) |
| **Вакансии** | — (прикладная) | Публикации вакансий, подходящих под условия программы |
| Участники | «Партнёры» (сделки) | Показ вознаграждения (рубли / вирт. валюта / бейдж) |
| Кандидаты | «Заявки» (сделки) | Вместо компании — «Фамилия И.О.» кандидата (закон о защите ПДн) |
| Посетители | «Посетители» (сделки) | — |

> [!gap] Вопрос Свешникову А. — унификация в SabyNet
> Как эти данные отобразятся в «обычном» унифицированном виде SabyNet? Проблема ровно с вкладкой «Вакансии», остальное — «обычное».

### 5. Доработка справочника источников — отв. Иван
В карточке кандидата и документе «Кандидат на вакансию» — выбор сотрудника источником **без указания реф. программы** (группа «По рекомендации»). Если сотрудника в источниках нет — выбрать из справочника сотрудников и добавить. Иконка — фото, название — ФИО. В отчёте «Источники кандидатов» (фильтр «По рекомендации») строки — сотрудники-рекомендатели; наведение → визитка, клик по ФИО → карточка сотрудника.
> [!gap] Цель этапа неясна — связать существующего кандидата с партнёром, чтобы сотрудник получил вознаграждение? Тогда фраза «без указания реферальной программы» противоречива.

### 6. Страница «Приведи друга» на карьерном сайте — отв. Иван
Только для сотрудников (действия только-для-сотрудника скрываются). Доступна при наличии экземпляра SabyNet-конфигурации типа «Вакансия». Пока **без** виджета рекомендаций (следующий этап).

### 7. Виджет «Реферальные программы» и карточка программы для карьерного сайта
Виджет в магазине виджетов: название, описание, картинка, награда. Клик по плашке → программа в диалоговом окне с кнопкой рекомендации и двумя вкладками:
- **Вакансии** — список подходящих; наведение → «Рекомендовать» + «Поделиться ссылкой»; клик по вакансии → страница вакансии в новой вкладке;
- **Я рекомендовал** — кандидаты, рекомендованные пользователем и откликнувшиеся по его ссылкам; дата, статус, награда по успешным.
- Развилка: два раздельных списка «я рекомендовал» / «можно рекомендовать» (решено — **два разных**).

### 8. Виджеты «Награда за рекомендацию» и «Рекомендовать» на вакансии — отв. Иван
- «Награда за рекомендацию» — что получит сотрудник (премия в рублях / корп. валюта / бейдж). Программа подбирается по **категории и компании** вакансии.
- «Рекомендовать» — открывает диалог заполнения и отправки рекомендации.
- Виджеты на странице вакансии, по умолчанию «Скрывать если нет данных» → в вакансии вне программы скрыты.
> [!gap] Вопрос Юле — алгоритм соответствия вакансии (организация + категория) реф. программе, учитывая иерархию организаций (в программе компания может быть родительской).

### 9. Генерация реферальной ссылки
По клику «Поделиться» формируется ссылка с «зашитыми» сотрудником и (если есть) реф. программой. В ссылку **по вакансии всегда** прокидывается сотрудник (кандидата могут принять на другую вакансию; проверка программы — в момент положительного решения).
- Из карточки программы — отв. **Витольд**: метод даёт URL страницы с фильтрами (организация + категории) + реф. код партнёра.
- Из карточки вакансии/публикации — отв. **Иван**: по публикации → вакансия → реф. программа → реф. код участника → URL публикации.
- Сдаётся вместе с этапом 10.

### 10. Отправка рекомендации и отклик на рекомендуемую вакансию — отв. Иван
По «Рекомендовать» — диалог с данными рекомендуемого. Проставляется источник партнёра (текущего пользователя) — **в отклик** (склоняются к этому). При отправке создаётся **отклик**: связан с публикацией сайта (если по вакансии) либо без вакансии. Группа реестра «По рекомендации»; отклики без публикации — в служебной записи «Без вакансии». Вместе с откликом создаётся карточка кандидата с источником-сотрудником.
- Два сценария создания кандидата: (а) вручную партнёром через «Рекомендовать»; (б) кандидатом по реф. ссылке.
> [!note] В реестрах отображаем отклики, но открываем карточку кандидата (см. понятийную модель).

### 11. Выдача вознаграждения за успешную рекомендацию — отв. Иван
При фиксации у кандидата нужного перехода/итога формируем поощрение сотруднику (из источника), связываем с документом «Кандидат на вакансию»; в комментарии — название программы + ФИО кандидата. Также — начисление в реф. программе через API рефералки (для статистики). Механизм: **служебный триггер** с условием (итог события для награды).
> [!gap] Через интерфейс рефералки SabyNet можно выдавать вознаграждение? На событии смены этапа кандидата (с учётом оптимизации) нужно обозначить рефералке выданное вознаграждение.

### 12. Виджет «Приведи друга» (SabyMy)
Виджет в личном кабинете SabyMy «Моя компания» на главной; клик → карьерный сайт на странице «Приведи друга».
