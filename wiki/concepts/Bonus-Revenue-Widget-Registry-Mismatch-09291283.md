# Что выяснено по коду
- Виджет «Доля выручки» (вкладка дашборда бонусов) считает выручку участников
  через внешний метод `RetailStats.SalesByClientsGroup` (группа клиентов `bonus`,
  поле SalesSum), см. `LoyaltyWidgetsOnline/.../bonuses/revenue_tab.py`.
- Итог «Выручка» в реестре Бонусы/Клиенты считается нами:
  `Bonus.GetClientListWithStatsTotals` → `get_client_sale_stats_totals(..., exclude_returns=True)`
  + статистика карт без клиента (`get_client_list_with_stats.py`).
- То есть цифры берутся из двух разных источников с разной логикой (разные классификации
  клиентов, обработка возвратов, отсечка ReferralSale). Расхождение ~27,6 тыс. само по
  себе не доказывает баг.
