# Сохранение ИНН/КПП клиента в корешках заявок SabyBank

Navigation: [[SabyBank-RKO-Referral]] | [[ReferralProgram-Stub-Implementation]]

Реализовано (сдано пунктом плана 2026-07-31, source: [[sabybank-inn-kpp-stub-storage-2026-07-31]]): корешок заявки SabyBank (`CreateStub`) теперь сохраняет ИНН и КПП клиента, зафиксированные на момент создания заявки.

## Статус

Чисто бэкенд-хранение — значения **нигде не отображаются на интерфейсе** на момент сдачи. Проверено демонстрацией: создание заявки → чтение корешка методом → возвращаемые ИНН/КПП совпадают с данными исходного клиента при создании заявки.

## Открытое

- [ ] UI-отображение ИНН/КПП в карточке заявки/реестре — не запланировано в этом пункте плана
- [ ] Источник не указывает точное поле хранения (`Атрибуты` корешка по аналогии с прочими полями [[ReferralProgram-Stub-Implementation]], либо отдельные колонки) — уточнить при следующем ингесте, затрагивающем реализацию
