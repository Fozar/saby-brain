Есть декоратор, который при обращении участника группы соцсети дергает тот же метод под владельцем группы.

- Например, вызов идёт из ext-registration в ext-registration, но под другим ClientID.
- Используем **TenantContext** + **EndPoint('online', auth\_data)**.
- Получаем петлю вызовов.
```python
auth_data = sbis.AuthByClientID(access_data.Get('ClientID'))
with sbis.TenantContext(auth_data):
    end_point = sbis.EndPoint('online', auth_data=auth_data)
    return sbis.BLObject(self.bl_object, end_point).Invoke(self.bl_method, *args)
```
